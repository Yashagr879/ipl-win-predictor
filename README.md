# 🏏 IPL Win Probability Predictor

A Machine Learning project that predicts the winning probability of IPL teams during the second innings using historical IPL match data and real-time match conditions.

## 📌 Project Overview

This project uses historical IPL match data to estimate the winning probability of the batting team during a live chase. The model considers the current match situation and predicts the chances of winning for both teams.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- Feature Engineering
- Logistic Regression Model
- Machine Learning Pipeline using Scikit-learn
- Real-time Win Probability Prediction

# IPL Win Probability Predictor

A machine learning web application that predicts the winning probability of IPL teams during the second innings using historical IPL match data.

## Features

- Real-time win probability prediction
- Machine Learning model using Logistic Regression
- Feature Engineering
- Interactive Streamlit UI
- Historical IPL Dataset

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Dataset

- matches.csv
- deliveries.csv
